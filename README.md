## 🚀 What is QuMail?

**QuMail** is a next-generation secure email platform that combines **AI-powered email intelligence** with **quantum-secure cryptographic mechanisms** to protect digital communication against evolving cyber threats and the future threat of quantum computing.

Traditional email was designed primarily for communication.

**QuMail is designed for communication + intelligence + security.**

It brings together:

* 🤖 **AI-powered email intelligence**

> **QuMail doesn't just send messages. It builds a security layer around the future of communication.**

# 2. ⚛️ Quantum Key Distribution

QuMail includes a simulated **Quantum Key Management Entity (KME)** architecture for demonstrating quantum key distribution concepts.

The system models:

```text
Sender
   │
   ▼
Quantum Key Generation
   │
   ▼
KME / Key Management
   │
   ▼
Secure Key Distribution
   │
   ▼
Receiver
```

The KME manages:

* Key generation
* Key distribution
* Key consumption
* Key lifecycle
* Key reuse prevention

The architecture follows the concepts of **ETSI GS QKD-014** for quantum key delivery.

> **Note:** The current implementation is a simulation/prototype of QKD infrastructure, not a physical quantum communication network.

---

# 3. 🔐 Multi-Level Security Architecture

QuMail demonstrates multiple security levels depending on communication requirements.

### Level 1 — Quantum OTP

One-Time Pad encryption using quantum-distributed keys.

### Level 2 — Quantum-Seeded AES

AES-GCM encryption using quantum-derived/managed key material.

### Level 3 — Post-Quantum Security

A simulated hybrid security approach combining quantum key distribution concepts with post-quantum cryptographic mechanisms.

### Level 4 — Plaintext

Traditional plaintext communication for compatibility/testing.

```text
Security Level
      │
      ├── 🟣 Quantum OTP
      │
      ├── 🔵 Quantum-Seeded AES-GCM
      │
      ├── 🔴 Post-Quantum Security
      │
      └── ⚪ Plaintext / Compatibility
```

This allows QuMail to demonstrate how different security models can coexist within one email platform.

# 🚀 Getting Started

## Prerequisites

Make sure you have:

* Node.js 18+
* npm
* PostgreSQL / Neon database
* OpenAI API access for AI features
* Required email provider credentials for external email integration

## Installation

```bash
git clone https://github.com/HuzaifaKhan-1/QuMail---Quantum-Secure-Email-Client-Application.git

cd QuMail---Quantum-Secure-Email-Client-Application

npm install
```

## Environment Variables

Create a `.env` file locally.

Example:

```env
DATABASE_URL=your_database_url

OPENAI_API_KEY=your_openai_api_key

SESSION_SECRET=your_session_secret

# Email provider configuration
SMTP_HOST=your_smtp_host
SMTP_PORT=your_smtp_port
SMTP_USER=your_smtp_user
SMTP_PASSWORD=your_smtp_password

# Microsoft Graph configuration if enabled
MICROSOFT_CLIENT_ID=your_client_id
MICROSOFT_CLIENT_SECRET=your_client_secret
MICROSOFT_TENANT_ID=your_tenant_id
```

### ⚠️ Security

**Never commit API keys, passwords, database credentials, OAuth secrets, or session secrets to GitHub.**

Use environment variables and keep `.env` in `.gitignore`.

# ⚠️ Security & Research Disclaimer

QuMail is an **experimental research/prototyping project** demonstrating concepts in AI-assisted communication, quantum key distribution, cryptography, and secure email.

The QKD/KME layer is **simulated in software** and does not represent a physical quantum communication network.

The project should not be interpreted as a guarantee of absolute security or "unbreakable" encryption.

Cryptographic implementations should undergo formal security review, testing, and independent auditing before being used for production-critical communication.
